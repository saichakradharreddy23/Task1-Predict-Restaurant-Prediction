Project Documentation & Architecture

About Restaurant Insight

End-to-End Machine Learning System for Restaurant Rating Prediction.

Project Mission & Objectives

In the modern hospitality industry, customer ratings dictate consumer trust, platform search ranking, and business viability. Understanding which features influence customer feedback allows restaurateurs and investors to make data-driven decisions on location, pricing, menu offerings, and digital services.

1. Empirical Data

Trained strictly on real-world dataset (9,551 restaurants, 141 cities, 15 countries).

2. Dedicated Algorithm

Exclusively powered by Random Forest Regressor (150 estimators, max depth 16).

3. Luxury UX

High-end food and restaurant aesthetic with dedicated coordinated palettes per page.

Machine Learning Workflow

1

Data Ingestion & Integrity Validation

Loads 9,551 records from data/Dataset .csv, handles missing values (9 in Cuisines imputed with mode), excludes zero-variance and leakage columns.

2

Leak-Free Preprocessing Pipeline

Splits 80% train and 20% test using random_state=42. Uses ColumnTransformer with median imputer and StandardScaler for numerical features, and OneHotEncoder for categorical features.

3

Random Forest Regressor Training

Trained with 150 decision trees, max_depth=16, min_samples_split=5. Cross-validated on training data (CV R²: 0.9576) and evaluated on test data (R²: 0.9592, RMSE: 0.3047).

4

FastAPI & Frontend Integration

Cached model pipeline for real-time inference, returning predicted ratings, qualitative badges, operational advice, and full exploratory search.

Technologies Utilized
